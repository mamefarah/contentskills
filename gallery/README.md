# Gallery

Finished example videos, shown on the dashboard's **Gallery** page (`npm run dashboard`, then http://localhost:4600/dashboard/gallery.html).
`index.json` lists what is shown; add a section or an item there to show more.

Only finished, approved work goes here. Drafts and test renders stay in `projects/<name>/out/`.

| Folder | What it is |
|---|---|
| `showcase/` | The 100-tile showcase sheet in two layouts: `showcase-16x9.jpg` (20 x 5, used in the README) and `showcase-10x10.jpg` (one category per row). One take through 90 library pieces, plus 10 frames from finished reels |
| `reels/` | Finished reels: whole videos made with this pipeline |

Videos are stored with Git LFS (see `.gitattributes`).
